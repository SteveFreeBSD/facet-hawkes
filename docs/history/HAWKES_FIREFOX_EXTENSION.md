# Hawkes Firefox extension — superseded

This was the pre-implementation design plan. It is **out of date** and kept
only so links to it do not dangle. Do not use it as a reference: it describes a
native-messaging protocol, permission set, and insertion strategy that the
built add-on does not follow, and several of its assumptions turned out to be
wrong once the editor was actually observed.
