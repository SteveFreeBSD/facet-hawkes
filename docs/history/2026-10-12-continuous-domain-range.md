## Routing boundary and entry

The live Chapter 3 prompt calls an affine equation and its graph a “relation”
and requests Domain and Range in interval notation. The previous graph route
required the word “graph,” so the finite-set handler claimed this continuous
relation and refused for lack of listed ordered pairs.

Domain/range requests now probe page-owned graph structure independently of
that keyword. Confirmed graph absence leaves written finite-set/equation
routing to Facet. Finite listed relations retain named finite-set results.
One exact affine equation, or explicitly verified linear graph geometry,
returns the existing typed `graph-domain-range` projection result.

A separately stated equation is carried with geometry and verified against
both defining points. Variable denominators, contradictory equations,
unsupported restrictions and ambiguous graph structure refuse without models.
Graph endpoints determine ray/segment bounds; viewport bounds do not.
Horizontal and vertical relations retain their singleton projection.

The existing model-owned Domain/Range labels determine field mapping. On an
interval-only surface, all real numbers renders as `(-∞,∞)` and a singleton
as `[a,a]`. Choice-bearing fieldsets retain their semantic all-real option.
Both use the existing graph projection adapter, interval planner and targeted
multipart `enterPlan` writer. No additional writer was created.
